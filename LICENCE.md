## 🧩 About

**Planet Zoo 2 Companion** is a curated list of Planet Zoo 2 open-source tools:

- **Overlays** — on-screen helpers, layout notes, exhibit planner, layout viewer
- **Quality-of-Life Helpers** — habitat catalog, animal notes, overlay reference
- **Research Notes** — park layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Park Helpers
- Exhibit Planner — sketch habitats from any checkpoint
- Layout Viewer — visualize enclosure boundaries
- Replay Notes — record and review park builds
- Playback Speed — adjust planner playback for study (0.1x to 5x)

### 🎨 Catalog & Cosmetics
- Animal Catalog — browse species, colors, traits, and notes
- Custom Skin Notes — organize park cosmetics
- Foliage Trail — improved vegetation visibility

### 🏋️ Planning Layout
- Planning Mode Notes — segment study on any layout
- Terrain Control — manually switch terrain layers in the planner
- Queue Buffer Notes — chain complex builds in the editor
